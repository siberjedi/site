# Git / Commit Kuralları

- Commit mesajlarına ASLA `Co-Authored-By`, `Signed-off-by` veya benzeri attribution/trailer ekleme. Commit'ler yalnızca kullanıcının adına atılır.
- Kendini (AI aracını) yazar, ortak yazar veya contributor olarak hiçbir commit'e / PR'a ekleme.
- Kullanıcı git konusunda deneyimli değil: push, pull, çakışma (conflict) gibi işlemlerde ne yaptığını ve kullanıcının ne yapması gerektiğini kısa ve basit şekilde açıkla.
- Commit mesajlarını repo'nun mevcut stiline uygun, kısa ve Türkçe yaz.
